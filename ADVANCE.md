# Advance

Advance one claimed builder unit, resolve the human frontier, or complete a route
transition, then stop. A continuation may resume the same work; the next builder unit
gets a fresh session.

## Orient

Load the charter, adopted principles, claimed unit, frontier, and only the units and
evidence that reach the selected work. An optional orientation index supplies verified
discovery pointers—entry points, environment facts, and linked references—never route
state. Reconcile the tracker with durable reality before selecting work.

Resume a live claimed unit. Otherwise choose one builder-owned frontier unit and
persist its `Claimed by` identifier before work. Before the first end-to-end result,
prefer work that can produce evidence from the thin complete path.

When only human-owned work is ready, present the choice, recommendation, main
downside, and the fact or exception that would change it. Ready questions may appear
together when they share one mental model and an earlier answer cannot change later
evidence; record each verdict independently. A clarification is not approval. A
declined recommendation can be a valid preference: revisit only premises the human
actually disputed.

When no unit is open, apply the Deferred rule in **Propagate**. If promotion creates a
unit, recompute the frontier and stop so a fresh session takes it. If Deferred is
empty and the terminal outcome is resolved, continue to **Close**.

## Resolve

Use research, a prototype, manual inspection, implementation, or read-only helpers as
the unit requires. Link durable evidence from the unit that needed it. Use
[REVIEW.md](./REVIEW.md) for a read-only review of any exact object and claim.

Resolve builder-owned decisions only from the charter, principles, and settled
evidence within builder authority. For repository outcomes, follow
[EXECUTION.md](./EXECUTION.md), then return here with its result. Other outcomes
finish when their stated result and evidence are acceptable as a whole.

For an authorized shared or external effect, verify the named target, scope, limits,
and preconditions immediately before acting. Destruction also requires an exact
recovery plan. If completion is ambiguous, reconcile external state before any retry.

If interrupted, leave one **Resumption checkpoint** containing durable commits or a
verified patch, current state, checks, and next step. A checkpoint with uncommitted
work remains claimed; release ownership only after the state is safely resumable.

## Propagate

Record the result and its provenance, then follow every dependent before the next
human question. Each affected unit stands, narrows, resolves, becomes moot, or
reopens. Record `stands` in that dependent's Resolution; before reopening, commit its
current Resolution so native history preserves the old verdict. Apply builder-owned
consequences and queue only residual human judgment.

Re-evaluate Deferred after every result and when no unit is open. Promote any item
whose activation evidence now holds before selecting a human frontier; remove an item
the exercised path proves unnecessary with a one-line reason; return uncertain
exclusion or charter change to the human. New units must satisfy the unit rule in
[Through-line](./SKILL.md#model).

When evidence contradicts an adopted principle, suspend it for the case and follow
[Challenge](./PRINCIPLES-GUIDE.md#challenge); only the human changes doctrine.

After two attempts at the same unit shape without new outcome evidence, rechart its
representation, boundary, or acceptance before a third. Return to the human when
that changes the charter, protected meaning, doctrine, or decision rights.

## Finish

Keep unit bodies current and rely on native tracker or Git history for superseded
text. Record a Resolution with provenance and evidence, or a checkpoint. Commit every
claim, verdict, checkpoint, resolution, reopen, and map transition promptly. Release
the claim only after resolution or a safely resumable checkpoint. Recompute the
frontier and update the orientation index only with expensive discoveries another
session would otherwise repay.

## Close

Close only when every unit resolves, Deferred is empty, and a terminal outcome records
the evidenced destination. A decision-only route sets the map resolved; its terminal
outcome is the durable summary. A repository route follows **Close the route** in
[EXECUTION.md](./EXECUTION.md). Validate durable state and stop.
